# GRC Mapping Reproduction Boundary

This repository hosts the reproducible, portfolio-safe implementation surface for the GRC Mapping Model.

## Public / reproducible scope

This side may contain:

- Sanitized graph samples
- Public relationship-record patterns
- Deterministic topology and robustness analyses
- Reproduction instructions
- Tests for orphan detection, concentration, coverage gaps, articulation points, bridges, and selected propagation behavior
- Public-safe result artifacts

## Protected scope

The following remain outside this repository and are validated in the private Multi-Framework Assurance research environment:

- Complete relationship taxonomy
- Proprietary scoring and calibration logic
- Private framework mappings
- Detailed validation rules
- Commercial datasets
- Sensitive evidence
- Experimental assurance mechanics

## Research provenance

Canonical theory and research history live in the GRC Atlas. This repository reproduces selected experiments in executable form. Protected calibration and validation live in GitLab.

**Notion explains the research. GitHub reproduces the visible experiment. GitLab protects and validates the deeper mechanics.**
