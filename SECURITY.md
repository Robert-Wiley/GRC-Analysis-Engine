# Security and Disclosure

This repository contains early-stage research and software supporting the GRC Analysis Engine and Governance Intelligence research program.

## Repository posture

- Keep the canonical repository **private** unless a deliberate release decision is made.
- Do not publish production credentials, API keys, connection strings, proprietary datasets, client information, or controlled assessment evidence.
- Keep public-facing descriptions at the capability and milestone level unless specific implementation details are intentionally approved for release.
- Treat scoring logic, analytical methods, confidence models, seam-analysis mechanics, and unpublished research constructs as non-public by default.

## Public disclosure rule

Public portfolio material may describe what the engine is intended to analyze and the stage of development. It should not disclose proprietary algorithms, internal formulas, source code, unpublished datasets, or implementation details.
